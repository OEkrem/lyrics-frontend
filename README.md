
# Lyrics Finder App V1.0

Bu proje, kullanıcıların sanatçı ve şarkı adı girerek şarkı sözlerini bulmasını sağlayan bir React uygulamasıdır. Ayrıca, önerilen şarkılar ve kullanıcı dostu bir arayüz ile kolay kullanım sunar.

---

## Proje Yapısı
```
src/
├── api/             # Backend ile iletişim kuran Axios bileşenleri
├── components/      # Uygulama içerisinde kullanılan bileşenler
├── layouts/         # Sayfa şablonlarını barındırır
└── pages/           # Kullanıcıya sunulan sayfalar
```

---

## Kullanılan Teknolojiler
- **React**: Kullanıcı arayüzü geliştirme
- **Axios**: API isteklerini yönetme
- **React Router**: Sayfa yönlendirme
- **Bootstrap**: UI tasarımı
- **npm**: Paket yönetimi

---

## 🚀 Nasıl Kullanılır?
### 1. Projeyi Klonlayın
```bash
git clone https://github.com/OEkrem/lyrics-frontend.git
cd lyrics-frontend
```

### 2. Gerekli Bağımlılıkları Yükleyin
```bash
npm install
```

### 3. Uygulamayı Çalıştırın
```bash
npm start
```
Uygulama, tarayıcınızda `http://localhost:3000` adresinde çalışacaktır.

### 4. Alternatif Olarak GitHub Pages Üzerinden Deneyin
Projeyi [buradan](https://oekrem.github.io/lyrics-frontend/) inceleyebilirsiniz.

---

## Özellikler
- **Şarkı Sözlerini Bulma**: Sanatçı ve şarkı adı girerek şarkı sözlerini görüntüleyin.
- **Toast Mesajları**: Kullanıcıya işlem durumu hakkında geri bildirim sağlayın.
- **Önerilen Şarkılar**: Hızlı seçim için önerilen şarkılar listesi.
- **Responsive Tasarım**: Mobil ve masaüstü cihazlarla uyumlu.
